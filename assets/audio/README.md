# Audio Assets

이 폴더에 오디오 에셋을 배치하세요.

## 필요한 파일들

### BGM (배경음악) - assets/audio/bgm/
Kenney Music 또는 유사한 무료 BGM 사용
- `main_theme.ogg` - 메인 화면 배경음악
- `game_theme.ogg` - 게임 플레이 배경음악
- `victory_theme.ogg` - 레벨 완료 배경음악

### SFX (효과음) - assets/audio/sfx/
Kenney UI Audio 추천 (https://kenney.nl/assets/ui-audio)
- `click1.ogg` - 버튼 클릭
- `switch2.ogg` - 글자 배치
- `confirmation_001.ogg` - 단어 완성
- `confirmation_002.ogg` - 레벨 완료
- `error_004.ogg` - 틀린 글자
- `maximize_006.ogg` - 힌트 사용
- `coin_001.ogg` - 코인 획득
- `confirmation_003.ogg` - 구매 완료
- `unlock_001.ogg` - 캐릭터 해금
- `jingle_achievement.ogg` - 뱃지 획득
